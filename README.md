# D3buff — чистая заставка и полный сайт

Это **полный автономный архив сайта**, а не набор правок, которые надо накладывать на предыдущую версию. В нём сам сайт, оригинальный видеофон, музыка, нужные шрифты, изображения, тесты, `server.js` и Windows-лаунчер.

## Запуск на Windows

1. Распакуй весь архив в любую папку.
2. Установи [Node.js](https://nodejs.org/), если он ещё не установлен.
3. Дважды щёлкни **`START_LOCALHOST.bat`**. Откроется `http://localhost:3000`.

BAT запускает локальный сервер из этой же папки и сам открывает браузер. Никаких `npm install` и подключения к интернету для сервера не нужно. Окно с сервером оставь открытым. Остановить его можно через **Ctrl+C**. Если порт 3000 занят, закрой прежний сервер.

Вручную: в командной строке из папки сайта выполни `node server.js`, затем открой `http://localhost:3000`.

## Заставка

На однотонном тёмном фоне — только лого и маленькая читаемая надпись **Click to continue**. У логотипа спокойное короткое появление без разлёта, осколков и других сложных эффектов. Нажатие плавно открывает профиль; можно нажать Enter или Space.

Музыка запускается непосредственно после действия пользователя: браузер не блокирует звук при первом открытии. До нажатия звук не включается.

На заставке нет снегопада, а после входа возвращаются боковые орнаменты: цвета инвертированы, стороны зеркальны. Основное лого сдвинуто на 2 пикселя влево. После входа сохраняется исходный видеофон `back/bg.mp4`.

## Профиль

Большой логотип — `image/logo.png`. Его оптическая ось выровнена с центром обложки, лого сдвинуто ниже, а штрихи инвертируют цвета реального фона под собой. Обложка `image/bg.png`, видео, музыка, ссылки, оформление профиля и карточки сохранены.

В `source-assets/` лежат присланные пользователем исходники логотипа и орнамента. По желанию поменяй `image/logo.png` на другую картинку с тем же базовым именем: код менять не нужно. Также можно заменить изображение баннера, сохранив имя `image/bg`.

## Проверка

При наличии Node.js запусти:

```bat
node --test tests/*.test.cjs
```

Полная копия сайта упакована в один `D3buff-localhost-complete.zip`. Это самостоятельная папка проекта: предыдущие архивы и рабочие файлы накладывать поверх неё не нужно. Опубликованный GitHub-сайт от этого локально не меняется.
